# Security

roast-my-design-system runs on your machine, reads the repository you point it at, and writes its output next to it. It makes no network requests and sends nothing anywhere.

If you find a security problem, email Greg Kozakiewicz through [gregkozakiewicz.com](https://gregkozakiewicz.com) or open a [GitHub issue](https://github.com/gregkozakiewicz/roast-my-design-system/issues) marked "security". Expect a reply within a few days and a fix in the next release.

Only the latest published version is supported.
