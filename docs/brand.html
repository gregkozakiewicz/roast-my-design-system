Brand and attribution

The software is free and open. The name and the mark are not part of that grant. This page says plainly what you may do with each, so nobody has to guess.

The name and the mark

roast-my-design-system™ and the GK mark are trademarks of Greg Kozakiewicz, in use publicly since July 2026. A licence to the code is not a licence to the brand.

  • Fine, no permission needed: saying your project is "built on roast-my-design-system", "a fork of roast-my-design-system", or "compatible with roast-my-design-system"; linking here; quoting the reports it generates.
  • Not fine: publishing a fork, service or paid product under this name or a confusingly similar one; using the GK mark as your own logo; implying this project endorses, maintains or is affiliated with yours.

If you fork it, give it your own name. That is better for you too: your users will find your docs instead of mine.

Attribution in generated reports

Every report the tool produces carries a footer crediting the project and its author, and every report carries an identifier that ties it to the version and scan that produced it. Removing that attribution from redistributed copies goes against the licence you received the code under.

Provenance

The canonical sources are the ones to trust: github.com/gregkozakiewicz/roast-my-design-system and the npm package, which is published from that repository through a signed, automated pipeline. Every release carries a provenance attestation you can verify. Anything distributed under this name from anywhere else is not mine.
