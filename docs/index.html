roast-my-design-system

Your design system, measured.

A free Claude Code + Codex skill. A deterministic scanner reads your repo and returns three things: a health score, the receipts behind it (every colour, spacing value, duplicated component and inline style, with real file paths), and the first fixes ranked by payoff. Benchmarked against 29 public repos and 10 reputable design systems. Read only, no network, one shareable HTML report.
